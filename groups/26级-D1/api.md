# ask.py 接口说明（v1，已冻结）

> 这个文件是「插座规格」：W6 做网页时直接按这里的输入输出接。
> 本文所有「实际输出」都来自 `tools/` 里的验证，不是凭记忆写的。

## 一、环境变量

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `LLM_API_KEY` | 是 | 无 | 模型服务的 key，只放环境变量，禁止进代码和仓库 |
| `LLM_BASE_URL` | 否 | `https://api.deepseek.com` | 任何 OpenAI 兼容服务都能填 |
| `LLM_MODEL` | 否 | `deepseek-chat` | 模型名，按服务商文档填 |

## 二、输入

```powershell
python ask.py ask "<问题>" [--json] [--top-k 3] [--index <索引路径>] [--offline]
```

| 参数 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `question` | 字符串 | 必填 | 用户的问题 |
| `--json` | 开关 | 关 | 输出 JSON，给程序读 |
| `--top-k` | 整数 | 3 | 取前几段资料拼进 Prompt |
| `--index` | 路径 | 脚本目录下的 `index.json` | 索引文件位置；给了相对路径就按当前目录解析 |
| `--offline` | 开关 | 关 | 不联网，只打印将要发送的 Prompt（调试用） |

## 三、输出

### 3.1 正常回答（文本）

```
（模型生成的答案，末尾带出处）

来源：docs/FAQ.md:4
```

### 3.2 正常回答（`--json`）

```json
{
  "question": "W3 的截止时间是几点？",
  "answer": "（模型生成的答案）",
  "sources": ["docs/考核与补交.md:3", "docs/FAQ.md:6"],
  "latency": 1.8,
  "tokens": {"prompt": 123, "completion": 45}
}
```

- `latency`：秒，保留两位小数。
- `tokens`：模型没返回 usage 时为 `null`，不省略字段。

### 3.3 拒答（检索零命中）

```
文档里没有
```
不调用 API，退出码 0；`--json` 时为：

```json
{
  "question": "食堂几点开门",
  "answer": "文档里没有",
  "sources": [],
  "latency": 0.0,
  "tokens": null
}
```

`question` 是问题原样回显（正常回答和拒答都有这一项），方便脚本把输出和问题对上；
`sources` 为空数组、`tokens` 为 `null`，字段不省略。

## 四、退出码

| 码 | 含义 |
|---|---|
| 0 | 正常回答，或正确拒答（文档里没有） |
| 1 | 环境/业务错误：缺 key、缺索引、网络失败、模型报错、空返回 |
| 2 | 命令行用法错误（argparse 自动） |

## 五、错误与实测输出

| 情况 | 实际输出（stderr） | 退出码 |
|---|---|---|
| 没设 key | `缺少 LLM_API_KEY。设置方法：` + PowerShell / CMD 两行 + 「key 不要写进代码」 | 1 |
| 没跑 index | `缺少 index.json，请先运行：python minisearch.py index docs/` | 1 |
| index 损坏 | `index.json 读取失败：<原因>` | 1 |
| key 无效（401） | `401：key 无效或已过期，检查 LLM_API_KEY` | 1 |
| 请求过频（429） | `429：请求太频繁，等一会儿再试` | 1 |
| 5xx / 超时 | 自动重试 1 次；仍失败 → `重试后仍失败：500：服务端错误` | 1 |
| 返回空内容 | `模型返回了空内容，请重试或换一个模型` | 1 |
| 返回格式异常 | `返回格式看不懂：<前 300 字>` | 1 |
| 环境变量含中文（照抄了「你的key」占位符） | `环境变量 LLM_API_KEY 里有非 ASCII 字符，请求发不出去。` + 常见原因 + 正确写法示例 | 1 |

## 六、两条硬约束（实现已遵守）

1. **数据库里没有就不调 API**：`find_passages()` 返回空列表时直接拒答，节省一次调用，也避免模型硬编。
2. **出处是拼进去的，不是模型猜的**：Prompt 里每段资料都带 `file:line`，模型只负责引用，不负责定位。

## 七、已知限制

- 检索是关键词两字组合 + 命中行数排序，同义改写可能搜不到（见 eval.md 的边界题）。
- 一段资料只取命中行本身，不含上下文，跨段落的答案可能拼不出来。
- 中文不分词，短于 2 个字的问题会退化成整句匹配。
