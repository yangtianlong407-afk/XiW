### 2.6 接本地假模型，把链路跑通

```powershell
# 窗口 A
```

```text

来源：docs/scope.md:8、docs/scope.md:25
```

```powershell
python ask.py ask "典型使用场景是什么？" --json
```

```json
{
  "question": "典型使用场景是什么？",
  "answer": "（模拟回答）技术答疑是蔡僮、蔡凯、饶宇轩。来源：docs/FAQ.md:4",
  "sources": ["docs/scope.md:8", "docs/scope.md:25"],
  "latency": 0.02,
  "tokens": {"prompt": 123, "completion": 45}
}
```

说明两点，避免误会：

- 上面那句「技术答疑是蔡僮…」是**假模型写死的**，不是真答案，只用来证明「解析 → 出处 → 输出」这一段通；
- 本机没装 `requests`，`ask.py` 自动退回标准库 urllib，stderr 会提示一行
  `提示：没装 requests，本次用标准库 urllib；建议 pip install -r requirements.txt`，功能不受影响。

装上 `requests 2.34.2` 后再跑同一条命令，输出同样正确（`latency` 从 0.02 变成 0.14），
说明「有 requests / 没有 requests」两条 HTTP 实现都验过。
